Getting Started

1

Download & Install

Visit cursor.sh and download Cursor for your operating system (Windows, macOS, or Linux). Installation is quick and easy!

2

Open Your First Project

Open Cursor and create a new folder or open an existing project. You'll see your files in the sidebar, just like in VS Code.

3

Start Coding with AI

Press Cmd/Ctrl + K to open the AI chat, or start typing and let Cursor suggest code completions. Try asking questions about your code!

4

Explore Features

Try the Composer feature (Cmd/Ctrl + I) to make multi-file edits, or use inline editing with Cmd/Ctrl + K for quick changes.

Pro Tips for Beginners

💡 Keyboard Shortcuts

  • Cmd/Ctrl + K - Inline AI editing
  • Cmd/Ctrl + L - Open chat panel
  • Cmd/Ctrl + I - Open Composer
  • Cmd/Ctrl + Shift + P - Command palette

🎯 Best Practices

  • Be specific in your AI prompts
  • Review AI suggestions before accepting
  • Use comments to explain complex logic
  • Keep your code organized and readable

🚀 Learning Path

  • Start with simple projects
  • Ask Cursor to explain code you don't understand
  • Use AI to generate boilerplate code
  • Practice reading and understanding AI suggestions
